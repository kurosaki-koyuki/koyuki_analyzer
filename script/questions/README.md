# questions · 问题排查档案

记录开发过程中**实际遇到并定位到根因**的问题，供后续快速避坑与复用排查思路。

## 目录约定

- 第一层：技术域（如 `PyQt5/`、`R接口/`、`算法/`、`打包发布/`）
- 第二层：问题类型（如 `同步与填充/`、`控件状态陷阱/`）
- 每篇 md：**一个根因对应一篇**，文件名就是一句话问题描述

## 单篇 md 建议结构

1. 现象（用户/界面表现）
2. 涉及代码（修复后的当前路径）
3. 定位过程（简要，避免“玄学改对”）
4. 根因（为什么会出现）
5. 最小修复（只改该改的）
6. 验证（如何证明已修复、如何复现）
